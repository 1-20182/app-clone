# 安装向导「选择安装位置」体验改进（2026-09-21）

> 需求原话：「安装的时候，安装程序选择安装路径的时候不便捷，要能够唤起文件选择器，
> 快速的选择安装路径才好。」
>
> 结论：**安装向导的路径行整段重做**。原实现里其实已经有一个「浏览…」按钮，
> 但它①用的是老式文件夹选择器且**没有初始目录**，②和输入框一起用 `Anchor` 布局、
> 在 200×100 的宿主里算出了负间距 —— 输入框会被撑到 860px 宽、糊住右侧按钮。
> 本轮把两件事一起修掉，并补上「快速定位」与拖放。

---

## 1. 问题分解

| # | 现象 | 根因 |
|---|---|---|
| 1 | 点「浏览…」弹出来的选择器每次都落在「此电脑」或桌面，要自己一路点进目标目录 | 原代码 `new FolderBrowserDialog { SelectedPath = _dir }`，而 `_dir` 默认是**尚不存在**的 `%LOCALAPPDATA%\Programs\应用分身`；目标目录不存在时老实现会忽略它。且没有 `InitialDirectory`、没设 `FOS_*` 选项 |
| 2 | 选择器里换盘符要多点两下，也看不到「此电脑」树 | 老式树控件不是资源管理器原生对话框 |
| 3 | **输入框盖住「浏览」按钮** | `txtDir` 用 `Anchor = Top\|Left\|Right` 加进一个构造期只有 **200×100** 的 `Panel`；WinForms 在此刻记下右间距 `200-(60+420) = -280`，等页面被 `Dock=Fill` 撑到 640 宽时列宽变成 `640-60-(-280) = 860` |
| 4 | 选盘符、选桌面这类高频路径全靠手打 | 没有快捷入口 |
| 5 | 每次重装都要重新找路径 | 安装位置没被记住 |

第 3 条是本轮最值得记的一课，与主程序 `MainForm` 那条「停靠顺序」血泪规则同源：
**`Anchor` 的间距是在控件被加入父容器的那一刻按父容器当前尺寸定死的**，
父容器后续被 `Dock` 撑开时，锚定间距不会重算，只会线性外推。

## 3. 关键技术点

### 3.1 为什么自己写选择器，而不用 `FolderBrowserDialog`

WinForms 自带的那个在这个场景下有四个硬伤：初始目录无从指定、标题与确认按钮文案不可定制、
导航窗格不保证出现地址栏、目标目录不存在时行为不可预期。

改用资源管理器原生对话框（`IFileOpenDialog` + `FOS_PICKFOLDERS`）后白拿三件事：

- **顶部地址栏可直接粘贴 `D:\应用分身` 回车直达** —— 换盘符真正的一步到位；
- 左侧导航树含「此电脑」，可展开所有盘符；
- 自带**新建文件夹**。

选项组合：`FOS_PICKFOLDERS | FOS_FORCEFILESYSTEM | FOS_PATHMUSTEXIST | FOS_NOCHANGEDIR`。
`Show` 用 `[PreserveSig]` 接 HRESULT，非 0（用户取消是 `0x800704C7`）直接当取消处理；
整段包在 `try/catch` 里，**任何异常都返回 `null`** —— 选择器永远不能把安装流程带崩。

初始目录由 `FolderPicker.NearestExisting()` 回溯到**最近一个真实存在的祖先**，
所以默认路径还不存在时也不会弹回「此电脑」；用户在地址栏里粘的路径同样适用。

### 3.2 布局回归：手算子控件，不用 `Anchor`

`PathSelector` 在 `OnResize` / `OnLayout` 里对每一列 `SetBounds`：

```
列宽 = max(120, 总宽 - 84(浏览) - 100(快速定位) - 8*2)
```

宽度完全由算术决定 ⇒ 可以用探针在 5 种宽度下逐项断言，且有一条
**「构造后立即取宽度也不越界」**的回归守卫，专门防止有人改回 `Anchor`。

顺带修掉同一类问题的一处：完成页「完成」按钮原本也是 `Anchor=Bottom|Right`。
另外把输入框的 `AutoSize` 关掉 —— 单行 `TextBox` 默认按字体高度（20 出头）走，
与同一行的 30px 按钮对不齐。

### 3.3 「快速定位 ▾」

一按弹出候选：默认位置 / **上次安装的位置** / 桌面 / 文档 / 用户程序目录，
以及**每个本机盘符的 `X:\应用分身`**（固定磁盘与可移动磁盘，标注可用空间）。
盘符项把「应用名」显式写进菜单文案，不做隐式拼接，避免「我选了 D 盘，它却装进 D:\应用分身」的意外。

收录规则：只有**真实存在**的「上次使用」才进候选；与默认位置或**当前路径**相同则不罗列（避免列了个等于现状的项）。

### 3.4 实时校验

路径行下方一句人话提示，八种情形分别给文案：空路径 / 非法字符 / 相对路径 /
盘符不存在 / 盘符根目录 / 需要提权的 `Program Files` / 目录已存在 / **已装过旧版本（会覆盖程序文件，但分身数据与登录状态不受影响）**。

修这个功能时顺手逮到一个小 bug：`SetPath()` 里若新值与当前文本**完全相同**，
`TextBox` 不发 `TextChanged`，提示就不会重算 —— 用户点「浏览」选中同一个已有目录时，
看到的还是「将新建」。现在 `SetPath()` 末尾无条件 `Validate()` 一次。

### 3.5 安装位置记忆

写 `HKCU\Software\FenShen\AppCloneSetup\LastInstallDir`（与卸载信息键分开，卸载不牵连）。
读回时会校验盘符仍存在，否则回退默认位置。

## 6. 已知边界

- 选择器只允许选**已存在**的文件夹（`FOS_PATHMUSTEXIST`）；要新建目录请用对话框自带的「新建文件夹」，
  或直接在路径框里手打路径 —— 安装时会自动 `CreateDirectory`。
- 「快速定位」的盘符项目标固定为 `X:\应用分身`，不记忆「上次在 D 盘用过哪个子目录」。
- 需要提权的位置（`Program Files`）只做**提示**不做阻止：安装器不请求管理员权限，
  真写到那儿会由系统决定是否 UAC 提权或写入失败。
- 安装位置的记忆写在注册表当前用户下，换用户账户后不共享。
